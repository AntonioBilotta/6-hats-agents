## Punti chiave

### Regola fondamentale delle sequenze
> "Sequences always begin and end with a blue hat."

Il [[cappello_blu]] apre e chiude ogni sessione senza eccezioni. Tra apertura e chiusura, la sequenza degli altri cappelli dipende dall'obiettivo.

### Sequenze ufficiali per tipo di attività

| Attività | Sequenza |
|----------|----------|
| Initial Ideas | 💙 → 🤍 → 💚 → 💙 |
| Choosing Between Alternatives | 💙 → 🤍 → (💚) → 💛 → 🖤 → ❤️ → 💙 |
| Identifying Solutions | 💙 → 🤍 → 🖤 → 💚 → 💙 |
| Quick Feedback | 💙 → 🖤 → 💚 → 💙 |
| Strategic Planning | 💙 → 💛 → 🖤 → 🤍 → 💙 → 💚 → 💙 |
| Process Improvement | 💙 → 🤍 → 🤍* → 💛 → 🖤 → 💚 → ❤️ → 💙 |
| Solving Problems | 💙 → 🤍 → 💚 → ❤️ → 💛 → 🖤 → 💚 → 💙 |
| Performance Review | 💙 → ❤️ → 🤍 → 💛 → 🖤 → 💚 → 💙 |

*🤍\* = White Hat per le prospettive degli altri stakeholder

### Timing raccomandato

- **Ogni cappello:** ~2 minuti
- **Bianco in apertura:** esteso (per allineare i fatti prima di procedere)
- **Rosso:** ~30 secondi — deve essere reazione viscerale pura, spesso implementato come dot-voting. Se dura di più diventa ragionamento travestito da emozione.

### Programmi emergenti
> "Programs are often emergent: the group might plan the first few hats then the facilitator will see what seems to be the right way to go."

La sequenza non deve essere pianificata interamente in anticipo. Il [[cappello_blu]] adatta in base a ciò che emerge.
